前端访问端口

管理后台「进入房间」、主题预览等链接使用此端口。默认 80；云厂商封 80 时可改为 1366 等（需在 nginx / 安全组放行）。

授权房间号
当前为拉取模式 (ROOMS_API_URL)，名单由外部 API 每 10 秒同步，此处只读。
外部 API 同步

填写外部 API 地址后系统将定期拉取房间号列表（竖线分隔），自动同步到白名单。已连接但不在名单中的房间将被踢出。
